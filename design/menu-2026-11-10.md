# Katuria's SEISHIN ATTACK：开始与结算界面

日期：2026-11-10。

## 最新品牌与机械入场

游戏名为 `Katuria's SEISHIN ATTACK`，GitHub 仓库名为 `seishin-attack`。
主标题使用固定 48px BM SPACE，斜切矩阵、四层硬边挤出及两条横向分色线；用户提供的作者 SVG 保留原路径，仅将橙色改成纸墨色，在主标题上方显示 Katuria's。Logo 由 `.scripts/prepare_author_logo.ps1` 生成。项目窗口与 Windows 导出名称同步更新，旧用户目录保留以兼容本地编辑器设置。

大厅加入 18Hz 步进运动、量化伺服视差、半像素胶片定位抖动、7Hz 分段扫描、卷轴驱动刻线与分段磷光指示条。战机独立顶层绘制，飞出时不会被人物遮挡。

开始/重试现在使用固定 1.92s 入场：0～0.28s 蓄力回收，随后二次加速飞出；0.68～1.04s 渐黑，1.12s 在黑屏下重置游戏并切换视口，1.20～1.92s 淡入局内。结束后直接运行游戏，无需松键，没有暂停画面。过渡期间屏蔽菜单/战斗输入，重复确认不重启过渡；Esc/Q/E 的按住状态在交接时同步。战斗模拟在淡入结束后启动，避免入场时已生成不可见敌弹。

## 画面

最新人物改为用户提供的飞行员少女，使用 `assets/menu/pilot_portrait.png`（1632×1536）。通过 `.scripts/prepare_menu_pilot.ps1` 从 Downloads 原图离线生成：移除右上对话框、外围背景转透明，保留人物护目镜、眼镜、枫叶发卡、手势、衣服排线。按 0.18 等比缩放，中心为 (554,266)，含最大视差仍位于右半边且不遮挡标题/按钮。旧图不再用于界面。

排版为 80 年代街机菜单：SEISHIN ATTACK 主标题、左侧命令、右侧原图。移除 1UP、FREE PLAY、1 PLAYER、READY、CREDIT 和底部署名，开始页仅保留品牌与 START / EXIT；结算保留实际统计与操作。菜单和数字使用 BM SPACE，标题 48px、命令 24px、统计 16px。

选中项使用反白条和闪烁 `>`；鼠标 hover 加深反白、滚动 2px 扫描亮线、进入时 0.12s 短促亮度跃变，以及间歇 1px 水平错位/低亮重影。按钮效果只绘制在当前按钮区域。人物另加独立故障着色：每 4.6s 在 1.10～1.42s 横向分片错位、局部断线及低亮重影，1.60～1.68s 二次短闪，其余时间完整恢复原图；24Hz 更新故障采样，无纹理重建。时钟由菜单推进，隐藏时停止。768×432 菜单画布仍经过已有 CRT，游戏分辨率保持 384×216；窗口缩放、曲率命中转换和结算流程沿用。

## 流程

- 主场景启动显示开始页，游戏模拟冻结。键盘 Enter/空格/X/Z 或点击 START 开始。
- 开始动作后播放战机飞出/黑屏/淡入入场，自动交接战斗，不再等待按键释放。菜单和过渡期间吞掉射击、换弹、轮换输入。
- 死亡保留 0.85s 原有反馈，再显示结算；分数、击杀、轮次及本局有效模拟时间从游戏状态快照读取。时间跨轮次累计，暂停不计。
- 结算的 RETRY 重新开局，TITLE 返回开始页。两页均可用 EXIT 退出程序。上下/W/S/Tab 循环切换选择，Enter 确认；R 始终选择开始/重试，即使当前选中 EXIT 也不会误退出；结算 Esc 返回。进入界面后 0.35s 内不激活，键盘自动重复忽略，持续按住开火不会自动跳过结算。
- 主场景通过 `front_enabled` 启用菜单。原有验证场景默认直达游戏，不为测试引入隐式全局开关。菜单隐藏时禁用其视口更新。

## 互动迭代

保留 BM SPACE、纸墨色和 CRT。标题加 3px 套印阴影，人物后方改为深墨斜切星场，44 个确定性星点分层闪动、每 7s 一次短流星，底部透视线缓慢前进，侧边扫描刻线循环移动。装饰不增加文字，不使用全局随机数。

人物直接加载预处理透明贴图，着色器按纹理实际尺寸生成窄纸色轮廓，保留原有故障、扫描和鼠标互动。

封面飞机通过 `preview_source` 引用实际游戏节点，复用 `_hull_xf`、`_body_slab`、`_fin_lead`、`_ventral_lead` 绘制主控战机，2 倍像素显示；保留侧视不对称机翼、钝机头、座舱、排气口和纸色机翼缝线，不修改游戏状态。

按最新反馈彻底删除纸浆、纤维、边缘磨损与文字保护区；底色使用纯色。标题、Logo、人物与背景一起通过最终 CRT 输出的统一噪点；平和版参数 `unified_noise=0.035`、grain=0.025、8Hz，替代此前过强的 0.15/0.12/18Hz。没有分层留白，游戏内统一噪点参数默认 0。作者 `'s` 基线由 49 下移到 54，对齐 Logo 底部。

- 鼠标在画面内移动时，人物最多偏移 5×3px，背景最多 8×4px；采用指数趋近，离开有效画面后平滑回中。标题和按钮命中区域保持固定。
- 开始页左侧加入小飞船和信号波形，飞船平滑跟随指针方向；尾焰与机体共用变换，窄喷口、多层亮芯、菱形激波与脱落粒子随起飞蓄力/加速伸长；结算页为统计留出原位置。
- 靠近人物时开启局部扫描线；点击人物叠加短暂故障强度，0.5s 内消退，与周期故障共存。
- 点击背景仅产生一圈细环，半径 2→18px，0.8s 扩散淡出，无火花、射线或旋转。点击冷却 0.12s，同时最多 6 组；按点击点距边框/标题/菜单/结算文字的最小距离整体限制半径，整圈保留中心对称，不逐段裁切。按钮点击仍只执行对应命令。
- 光标为 12px 四角空心准星，悬停收拢至 9px，点击轻微压缩后回弹；无中间箭头、拖影或额外侧标。反馈层在人物与战机上方，光标坐标沿用 CRT 曲率映射；窗口内菜单替换系统光标，离开窗口、进入游戏、退出时恢复。
- 每次进入开始或结算页重置视差、扫描、点击波和飞船位置；隐藏菜单时沿用已有视口停更机制。
