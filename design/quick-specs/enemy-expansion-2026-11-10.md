# 敌种扩充：自杀无人机与激光炮台

日期：2026-11-10。状态：已实装并完成自动验证；人体难度体验待试玩。
类型：现有敌机系统的增补。
依据：`NOTES.md` 的敌机运动、纸墨轮廓、受击分级与难度阶梯；`scripts/waves.gd` 的威胁预算。
本项目暂无独立 GDD、实体注册表或历史 quick spec，以交接文档和当前代码为准。

## 共同约束

两种敌机增加可读的决策，不通过提高弹量制造难度。每种敌机先单独介绍，再参与混编。以下是当前初始参数，不代表已完成真人平衡调优。

- 只从右侧入场，预警完成前不造成攻击伤害；不在玩家身边生成。
- 画法沿用实心墨块、纸色外晕和少量纸缝，不增加颜色、发光球或文字提示。
- 伤害走 `hurt_player()`，遵守护盾、反甲、无敌时间和死亡逻辑。
- 普通场上上限仍为 10～12，最多 3 架一波；特殊单位计入射击单位上限。
- Boss、精英和对手机期间不投放；未完成编队在大型战斗开始时取消。
- 新敌种引入后的两波只用旧碎片机陪衬；首次同时存在不超过 1 架。
- 第一次投放不得发生在下一位 Boss 到来前 6 秒内。
- 新类别必须使用显式枚举和分支；当前 `step_foes` 的兜底 `else` 是线圈行为，不能直接添加 kind=3/4 后任其落入。

## 自杀无人机

定位：让长时间停在同一位置的玩家做一次横向或纵向换位；冲刺锁定之后，玩家移动就能骗过它。

| 参数 | 初值 | 可调范围 |
|---|---:|---:|
| 出场 | 第 2 轮，波次时钟 ≥20s | 第 2～3 轮 |
| 威胁成本 | 3 | 3～4 |
| 半径 | 5px | 5～6px |
| 血量 | 2，第 5 轮后 3 | 2～3 |
| 入场时长 | 1.35s，减速停泊 | 1.2～1.6s |
| 预警 | 0.85s | 0.75～1.10 |
| 冲刺速度 | 190→335px/s，0.16s 加速 | 300～350 峰速 |
| 冲刺时限 | 1.25s | 1.0～1.5 |
| 自爆伤害范围 | 11px | 9～13 |
| 同屏上限 | 1，与炮台共享名额 | 固定 1 |
| 投放间隔 | ≥9s | 8～12 |

状态顺序：

1. **接近**：沿轻微弧线从右侧减速飞到 x=314；收拢的双翼随停泊展开，尾部有短促推进焰。玩家距其不足 56px 时推迟锁定；入场超过 4s 仍无安全距离则向右撤离，不能贴脸开启冲刺。
2. **标定**：停留 0.85s，前 0.55s 朝向玩家，最后 0.30s 冻结方向。机体纸缝、1px 高光与机头前 10～20px 的短断线标识蓄能，不贯穿整个屏幕。
3. **冲刺**：沿固定方向加速至 335px/s，完全不追踪，不允许中途转弯。起飞前轻微后坐，冲刺中收翼；19±4px 推进焰、1px 白核与 0.22s 世界坐标残迹表现高速。采样间距至少 2px、最多 48 点，5 个冷色尾屑不增加泛光。
4. **终止**：接触玩家后自爆一次，或冲刺结束后作 0.34s 无伤翼片散解。击毁后保留 0.46s 机翼碎片。离开画面直接清除，不在屏外制造爆炸。取消攻击后的撤离会收翼、转向，逐步加速飞离右边框。

玩家击毁时只做小型碎裂，不触发伤害爆炸、不转成敌弹。主动攻击应当消除威胁。
接触和自爆共用一次伤害判定，不能同帧扣两次；玩家无敌时消耗无人机但不扣血。反甲可击毁周围无人机，不连锁引爆。

编队搭配：单机介绍 → 与两架碎片机错开 0.45s 的突击箭头。禁止与激光同时锁定；不从两个方向同时冲刺。

验收：

- 锁定结束后横移可躲开，冲刺方向在所有帧率下保持不变。
- 从最早可见预警到伤害至少 0.85s；预警中被击毁不残留攻击。
- 护盾只消耗一次，反甲、无敌、ERASE 和死亡重开均无残留状态。
- 与场景中普通弹、星点和流星能在原始 384×216 画面上区分。

## 激光炮台

定位：短暂占用一条射线，鼓励预判移动和优先击杀；不是持续追踪玩家的扫屏光束。
形态为从右侧进入、悬停的重型平台，不贴在地形上；当前工程没有地形碰撞系统。

| 参数 | 初值 | 可调范围 |
|---|---:|---:|
| 出场 | 第 3 轮，波次时钟 ≥18s | 第 3～4 轮 |
| 威胁成本 | 4 | 4～5 |
| 半径 | 9px | 8～10px |
| 血量 | 6，每两轮 +1，上限 9 | 6～9 |
| 停泊位置 | x=300～325 | x=290～330 |
| 入场时长 | 1.70s，减速停泊 | 1.5～2.0s |
| 首次准备 | ≥1.0s | 1.0～1.4 |
| 蓄能预警 | 1.10s | 0.95～1.30 |
| 最后锁向 | 最后 0.40s 固定 | 0.35～0.50 |
| 有效激光宽 | 3px | 2～3px |
| 射击持续 | 0.24s | 0.18～0.30 |
| 冷却 | 3.4s | 3.0～4.0 |
| 最长驻留 | 15s 或 3 次射击 | 12～16s |
| 同屏上限 | 1 | 固定 1 |

状态顺序：

1. **入场**：沿轻微弧线减速飞入停泊位，散热片和双叉炮口逐渐展开。宽底座、分叉炮口、横向纸缝形成轮廓身份；不做环状本体，避免像线圈。
2. **追瞄**：预警前 0.70s 跟随玩家，炮口窄缝逐步张开。1px、低亮断续墨线标出真实射线，绝不使用与背景流星同样的短斜尾形状。
3. **锁向**：最后 0.40s 射线静止；断线变实线但保持细。玩家有明确离开射线的窗口。
4. **开火**：3px 墨色束、1px 纸色内缝、5px 纸边；仅炮口 3px 白核进入现有泛光管线，束身不泛白。方向在整个射击期间不变，射线终点裁到游戏内框。
5. **散热**：3.4s 内不具攻击性。完成三次射击或达到驻留上限后收起散热片和炮口，炮口转向右侧；用 0.8s 收拢部件，离泊速度在 1.1s 内由 12px/s 加速至 78px/s，完全出框后删除。击毁后短暂保留分离的底座、装甲和散热片，纯视觉残片不留攻击。

碰撞使用玩家圆形判定与有限线段的最近点距离。渲染端和伤害端共用起点、方向、最大长度和宽度数据。
一次光束最多伤害一次，不依赖 1.35s 无敌恰好长于光束寿命来避免重复扣血。
炮台被击毁、遭 ERASE、切换 Boss 或游戏重开时，预警和有效光束同帧撤销。
ERASE 清除当前光束并使未被摧毁炮台回到完整冷却；不会在下一帧补射。

编队搭配：第一次孤立投放；后续“炮台＋上下两架碎片机”护航形。炮台参与后必须替换旧单位，不能附送第四架。与无人机共享特殊威胁锁，禁止激光封路时无人机冲刺。

验收：

- 预警射线、有效束和碰撞范围一致；锁向后移动可以规避。
- 同一次束命中只触发一次伤害事件；护盾、暂停、低帧率不改变结果。
- 炮台死亡或阶段切换后不存在不可见伤害束。
- 最后锁向的 0.40s 不被流星、掉落闪光或大量普通弹掩盖。

## 实现次序与验证

行为和共享射线几何位于 `scripts/special_enemies.gd`；波次预算位于 `scripts/waves.gd`，调度与统一伤害入口位于 `scripts/game.gd`。

第 2 轮波次时钟 ≥20s 尝试首次无人机，第 3 轮 ≥18s 尝试首次炮台。大型战斗期间时钟冻结；名额、预算、回落段或 Boss 前窗口不合适时延后，不强塞入场。首次单机介绍，随后两波只有碎片机；后续特殊波最多加两架碎片护航，错开 0.45s。特殊成本分别为 3/4，计入射击单位上限，每次替换原波次而非额外加怪。

无人机和炮台共用一个名额（含入场队列和撤离阶段），从投放算起最短间隔分别为 9/12s。无人机击毁只碎裂，无连锁自爆。ERASE 使幸存炮台进入完整 3.4s 冷却；Boss、精英、对手机和死亡会立即撤销特殊攻击并令其撤离。

运行 `.scripts/check_special_enemies.gd`：12,428 项断言，0 失败。包含 30/60/165fps、dt=0.05 的预警长度、锁向与最短锁定时间；32 个方向的有限射线裁切和宽度正反对照；单次护盾、无敌、击毁、反甲、ERASE、死亡、重开、大型战斗清理；32 个随机种子、4 档循环的入场门槛、预算、介绍两波与名额互斥。既有波次 89,432 项断言与爆炸、对手机调度、武器字形检查通过。

实际 CRT 抓帧检查蓄能、开火、无人机冲刺与纸面/月盘上的敌弹轮廓；白核经现有 bloom 提取和合成，不提高全局泛光强度。敌弹外观在 `scripts/hostile_projectiles.gd` 区分尖镖、线圈菱片、棱晶、机枪短弹与重型弹壳，最多 12 个敌弹白核同时进入泛光。

入场/离场增补：`.scripts/check_special_animation.gd` 共 5,342 项断言通过，覆盖多帧率减速停泊和加速撤离、部件展开/收拢、取消幂等、击毁与自然散解、残片暂停/去重/容量/过期/重开。残片最多 8 组，与伤害立即分离；使用独立绘制快照，寿命结束后回收，不生成节点或额外敌弹。八时刻实机序列包含入场、停泊、耗尽散解、撤离、击毁和清空。

真人试玩重点：第一次见到能否读懂；使用基础枪是否有合理击杀窗口；两种威胁与旧弹幕重叠时是否仍能找到安全路线。没有试玩数据前不宣称平衡完成。
